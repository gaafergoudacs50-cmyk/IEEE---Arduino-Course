1.Core Architecture of Embedded Systems

An embedded system combines specific hardware with dedicated software to perform a targeted function, operating entirely within a larger mechanical or electrical system. Common commercial examples include the digital control boards inside air conditioners or the touchscreen interfaces on smart refrigerators.

Microprocessors (µP) vs. Microcontrollers (µC)

Microprocessor (µP)

Acts solely as the CPU, requiring external, separate chips for memory and I/O ports.

Microcontroller (µC)

Integrates the CPU, memory, and I/O ports into a single Integrated Circuit (IC) chip.

ICs come in different packaging types, such as Through Hole Devices (THD) and Surface Mount Devices (SMD).

2.The Arduino Hardware Platform

Arduino is an open-source hardware and software platform functioning as a micro-computer on a board, utilizing a programming language derived from C++. The standard Arduino Uno board features several critical physical components and pin categories:

Power Delivery

The board includes a USB jack, a barrel jack, and a built-in voltage regulator. The Vin pin supplies voltage to the board (optimally 7-12V) or acts as a voltage output, while the 5V and 3.3V pins output those exact regulated voltages. The GND pins serve as the common 0V ground.

Digital I/O (Pins 0-13)

These 14 pins can be programmed as either inputs or outputs. Pin 13 is internally wired to a built-in LED on the board itself.

Analog Inputs (Pins A0-A5)

These 6 pins are primarily used to read analog input signals, though they can also read digital inputs. If configured as outputs, they can only produce digital signals.

3.Prototyping Hardware and Circuitry

Building embedded projects requires standardizing the physical connections between the microcontroller and external electronic components.

  • LEDs (Light Emitting Diodes): These are polarized components with a positive leg (anode) and a negative leg (cathode).
  • Resistors: Used to limit current, resistor values are calculated using Ohm’s Law (V = IR). For example, if powering an LED that drops 2V from a 5V Arduino pin, the resistor must drop the remaining 3V. Limiting the current to a safe 15mA (below the 20mA maximum) requires a 200 Ω resistor (R = 3V / 15mA). Resistor values are identified using standardized color-coded bands detailing digits, multipliers, and tolerance.
  • Breadboards: These solderless boards contain hidden metal clips. The outer power rails run horizontally along the entire length of the board, while the inner component rows are connected vertically in short blocks of five holes. This layout allows components to be easily wired in series (one after another) or parallel.
  • Jumper Wires: Connections are made using Male-Male, Male-Female, or Female-Female jumper cables depending on the component headers.

4.Software Integration and Execution

The software side is handled by the Arduino IDE, an environment containing all necessary instructions to command the hardware.

  • IDE Setup: The interface includes a text editor for the code, a message area for compilation feedback, and toolbars for common commands. Before uploading, the user must navigate to the Tools menu to select the correct Board (e.g., Arduino Uno) and the active Port (e.g., COM3).
  • Code Structure: Every Arduino script requires a setup() function that runs a single time to initialize settings, followed by a loop() function that executes continuously.
  • The Blinking LED Task: To program an LED to blink indefinitely at one-second intervals, the setup() function uses pinMode(13, OUTPUT) to initialize pin 13. The loop() function then uses digitalWrite(13, HIGH) to turn the LED on, delay(1000) to pause for one second (1000 milliseconds), digitalWrite(13, LOW) to turn it off, and another delay(1000) before the cycle repeats.
void setup() {
  pinMode(13, OUTPUT);      // initialize pin 13
}

void loop() {
  digitalWrite(13, HIGH);   // LED on
  delay(1000);              // wait 1 second
  digitalWrite(13, LOW);    // LED off
  delay(1000);              // wait 1 second
}

setup() runs once, loop() repeats forever.

Assignments

Connect the LEDs wherever you like. Initially they are all off, and each sequence repeats forever.

3 LEDs (X, Y, Z)

  1. Turn on LED X, wait 0.1 second.
  2. Turn on LED Y, wait 0.1 second.
  3. Turn on LED Z, wait 0.1 second.
  4. Turn them all off.
  5. Repeat forever.

5 LEDs (A, B, C, D, E)

  1. Turn on LEDs A and E, wait 0.08 second.
  2. Turn on LEDs B and D, wait 0.08 second.
  3. Turn on LED C, wait 0.08 second.
  4. Turn them all off.
  5. Repeat forever.

Hint: start from the blinking LED sketch and add one pin per LED.
